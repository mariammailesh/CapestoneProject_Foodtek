# Foodtek CapestoneProject
### Food Delivery Database & RESTful API (Database-First with ADO.NET + EF)

This project showcases the **implementation of a complete database design and back-end RESTful API** for a **food delivery mobile application**, developed using a **Database-First workflow** that combines **ADO.NET** and **Entity Framework**.  

## Project Overview

1. **Database Design & ERD**  
   - Designed a **comprehensive SQL Server database**  
   - Created an **ERD** showing tables, keys, and relationships  

2. **Initial Implementation with ADO.NET**  
   - Connected the app to the database using **ADO.NET**  
   - Followed a **Database-First approach**  

3. **Scaffolding to Entity Framework**  
   - **Reverse engineered the database** into EF entities and a `DbContext`  
   - Used **ADO.NET Entity Data Model (EF Designer)** in Visual Studio  

4. **Back-End RESTful API**  
   - Built **API endpoints** for:  
     - Browsing menus  
     - Placing and tracking orders  
     - Managing user profiles and deliveries
     - etc

## Outcome
A **robust and scalable back-end** that:  
- Keeps the database as the **single source of truth**  
- Provides a **RESTful API** for the mobile app  
- Ensures **clean data access** via Entity Framework
